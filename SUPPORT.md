# Support

## Read the docs first

Start with the [documentation site](https://smartsquad.github.io/expo-apple-sign-in/). The [Troubleshooting page](https://smartsquad.github.io/expo-apple-sign-in/reference/troubleshooting.html) lists known errors with their causes and fixes.

## Ask a question

If the docs do not answer your question, [open an issue with the question form](https://github.com/smartsquad/expo-apple-sign-in/issues/new?template=question.yml). Use the [bug report form](https://github.com/smartsquad/expo-apple-sign-in/issues/new?template=bug_report.yml) for a defect and the [feature request form](https://github.com/smartsquad/expo-apple-sign-in/issues/new?template=feature_request.yml) for a proposal.

## What to include

- Give the Expo SDK version and the `expo-apple-sign-in` version.
- Name the platform: iOS, Android, or web.
- Say whether you run a development build.
- Paste the error `code`, such as `ERR_NOT_CONFIGURED`.

Redact identity tokens, authorization codes, and nonces from every log and code sample you share.

## What is not supported

- Expo Go is not supported because it does not include the native module. Use a development build through `expo run:ios`, `expo run:android`, or EAS Build.
- Expo SDK versions below 58 are not supported.
- Apple account and App Store Connect problems are outside this project. Contact Apple Developer Support for them.
